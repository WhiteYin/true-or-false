# 首页实现范围

依据：会话“评估新闻核验站实施方案”最终的《首页设计与实施要求》与《首页样式规范 v1.0》，2026-10-28。

本阶段以可点击的本地首页为交付目标。原先完整核查系统的数据库、队列、联网检索、模型 API 和部署工作均属于后续阶段。

视觉变量集中在 `src/app/globals.css`。使用系统中文字体，不请求外部字体服务；品牌为真实文本，黄色强调块仅由 CSS 绘制。

验收宽度：1440、1024、768、390、320px；同时关注长链接、2,000 字符、3 张截图、空提交、仅图片提交、键盘焦点与弹窗恢复。实际验证结果见 `docs/verification.md`。
