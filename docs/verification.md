## 交互

| 场景 | 实际结果 |
|---|---|
| 完全空白提交 | 出现“请输入待核查内容，或添加截图”，输入框获得焦点 |
| 点击示例 | 文案填入输入框，聚焦输入框，不自动提交 |
| Enter | 输入换行，不打开提交弹窗 |
| 2,000 字符 | 显示字数；继续键入不会超过限制 |
| 长链接 | 自然断行，达到 280px 手机文本区上限后内部滚动 |
| 有文字提交 | 打开“内容已准备好”，明确核查服务未接通 |
| 仅图片提交 | 正常打开提示弹窗 |
| 关闭或 Escape | 保留文字、截图，焦点恢复到“辨真假”按钮 |
| 弹窗 Tab、Shift+Tab | 焦点在两个弹窗按钮间循环，不落到背景控件 |
| 本地选择 3 张 JPEG | 显示完整缩略图和文件名，不进行上传 |
| 第 4 张图片 | 提示最多 3 张，保留已有图片 |
| 移除后重新选择相同文件 | 可以再次添加；移除后焦点回到“添加截图” |
| 非图片文件 | 明确提示仅支持 JPEG、PNG、WebP |
| 10MB + 1 字节图片文件 | 明确提示图片超过 10MB |
| 损坏 PNG | 解码失败后明确提示图片无法读取，不保留无效缩略图 |

图片通过浏览器 `File` 与对象 URL 解码、预览，代码中没有上传、核查请求或本地持久化调用。文件选择测试只使用本项目生成的测试截图和无效文件。测试临时文件位于被 Git 忽略的 `test-results/`。
