# 真的假的.com：首页样式规范 v1.0

配合《首页设计与实施要求》使用。本规范明确视觉、尺寸和响应式行为；功能范围保持为可点击的首页原型。

## 1. 设计方向

关键词：**醒目、直接、清晰、可信。**

首页以大字品牌和宽敞的输入区为视觉中心。明黄色负责品牌识别，墨黑色建立层级，白色输入区保证长文本的可读性。

使用平面色块、明确边框和少量硬边阴影。避免渐变、毛玻璃、发光效果、大幅背景插画以及过多悬浮卡片。

页面主要视觉顺序：

**真的假的.com → 输入框 → 辨真假 → 示例问题 → 核查说明**

## 2. 色彩规范

| 变量 | 色值 | 用途 |
|---|---|---|
| `--page-bg` | `#F7F6F0` | 页面暖白背景 |
| `--surface` | `#FFFFFF` | 输入区、弹窗 |
| `--ink` | `#171717` | 标题、正文、按钮背景 |
| `--text-secondary` | `#595950` | 说明文字、示例区标题 |
| `--text-muted` | `#707066` | 字数、辅助说明 |
| `--brand` | `#FFE500` | 品牌色块、悬停强调 |
| `--brand-hover` | `#F2D900` | 黄色交互区域悬停 |
| `--border` | `#D9D9CE` | 普通分隔线与次要边框 |
| `--border-strong` | `#171717` | 主输入区边框 |
| `--focus` | `#2457E6` | 键盘焦点 |
| `--error` | `#B42318` | 校验错误 |
| `--error-bg` | `#FFF1EF` | 错误提示背景 |

使用规则：

- 正文和操作文案优先使用墨黑色。
- 黄色区域搭配墨黑文字，不使用白字。
- 页面只使用黄色作为主要品牌强调色；蓝色仅用于焦点。
- 错误需同时出现图标和文字，不能只改变边框颜色。
- 文字对比度以 WCAG AA 为验收目标，实际实现后检查。

## 3. 字体与字号

使用系统中文无衬线字体，无需依赖外部字体服务：

`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif`

| 元素 | PC ≥ 1024px | 平板 768～1023px | 手机 < 768px | 字重 / 行高 |
|---|---:|---:|---:|---|
| 中文品牌标题 | 96px | 72px | 56px；窄屏降至 44px | 900 / 1.12 |
| `.com` | 36px | 28px | 22px；窄屏 18px | 800 / 1 |
| 简短说明 | 18px | 17px | 16px | 400 / 1.65 |
| 输入正文 | 18px | 17px | 16px | 400 / 1.75 |
| 主按钮 | 18px | 18px | 18px | 700 / 1 |
| 示例问题 | 14px | 14px | 14px | 500 / 1.5 |
| 辅助文案 | 13px | 13px | 12px | 400 / 1.6 |
| 弹窗标题 | 24px | 24px | 22px | 700 / 1.4 |

- 中文标题字距约 `-0.04em`，正文使用正常字距。
- `.com` 与中文标题基线对齐，间隔 8～12px。
- 品牌整体居中，保持单行；在 320px 屏宽下也必须完整显示。
- 标题使用真实文本，不能将整段文字做成图片。
- 若系统没有 900 字重，允许回退至 700。

## 4. 布局与间距

采用 4px 间距基准，常用间距为：

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80`

页面主体最大宽度 **800px**，居中排列。

| 布局项 | PC | 平板 | 手机 |
|---|---:|---:|---:|
| 页面左右内边距 | 32px | 24px | 20px；≤360px 时 16px |
| 主体顶部留白 | 96px | 72px | 48px |
| 标题到说明 | 20px | 16px | 16px |
| 说明到输入区 | 40px | 32px | 28px |
| 输入区到主按钮 | 16px | 16px | 12px |
| 主按钮到示例区 | 32px | 28px | 28px |
| 示例区到体验版提示 | 24px | 24px | 20px |
| 主体到底部说明最小距离 | 64px | 48px | 40px |

页面使用最小视口高度，内容不足时将底部说明推向页面下部；内容增多时随页面自然滚动。不得用固定定位将底部说明覆盖在输入区或手机键盘上方。

## 5. 品牌标题

显示完整文案：**真的假的.com**

推荐将“假的”背后放置一块明黄色平面色块：

- 色块略微倾斜约 `-2deg`，文字本身保持水平。
- 色块上下比字形多留 4～6px，左右多留 6～10px。
- 色块使用小圆角 4px，不加阴影。
- `.com` 使用墨黑色，不单独放置到第二行。
- 标题旁不再添加装饰性徽章，避免削弱品牌本身。

简短说明居中显示：

> 别急着转发，先看看证据。

## 6. 输入区

输入区作为一个完整组件，内部从上到下包含：

**多行文本框 → 图片预览（有图时）→ 底部工具栏**

外观：

- 白色背景。
- 2px 墨黑边框。
- PC 圆角 16px，手机圆角 12px。
- 静止时使用 `4px 4px 0 #171717` 的硬边阴影；手机减为 `3px 3px 0 #171717`。
- 外部阴影必须计入页面宽度，避免窄屏溢出。
- 文本框本身透明、无额外边框，避免双层输入框。

文本区域：

| 属性 | PC | 手机 |
|---|---:|---:|
| 内边距 | 24px | 16px |
| 初始文本区高度 | 180px | 152px |
| 自动增长最大高度 | 360px | 280px |
| 输入区工具栏高度 | 至少 56px | 至少 52px |

- 长文本自动换行，长链接允许断行。
- 超过最大文本区高度后，文本区内部滚动。
- 输入文字左对齐，不使用居中排版。
- 占位文案使用 `--text-muted`，最多呈现三行。
- 工具栏与文本区不使用粗分隔线，可使用 1px 浅色线。
- 输入区聚焦时，在外侧显示 3px 蓝色焦点线，间隔 3px；不改变尺寸。

占位文案：

> 粘贴一条新闻、一段传言或原文链接……  
> 也可以添加截图，补充你想核实的内容。

## 7. 输入区工具栏与图片

工具栏左侧为“图片图标 + 添加截图”，右侧为字数，如 `128 / 2000`。

“添加截图”按钮：

- 透明背景，墨黑文字，图标 18px。
- 字号 14px，字重 500。
- 点击区域至少 44 × 44px。
- 内边距 10px 12px，圆角 8px。
- 悬停背景 `#F1F1E8`。
- 手机端保留完整文字，不只显示图标。

图片预览：

- 放在文本区下方、工具栏上方。
- PC 缩略图 88 × 88px，手机 72 × 72px。
- 缩略图间距 12px，最多三张。
- 圆角 8px，1px 浅色边框。
- 使用 `object-fit: contain`，保留新闻截图的完整内容；空白处使用浅灰底色。
- 每张图片右上角提供可见的移除按钮，不依赖鼠标悬停才出现。
- 移除图标视觉尺寸 20～24px，实际点击区域至少 44 × 44px。
- 文件名称和错误文案以文本呈现，不能撑破容器。
- 图片较多导致空间不足时换行。

拖入图片时：

- 输入区背景变为浅黄色 `#FFFBE0`。
- 显示“松开以添加截图”。
- 拖动结束后恢复，不引发组件高度跳动。

## 8. 主按钮

文案：**辨真假**，右侧可配 20px 向右箭头。

- PC、平板和手机均使用输入区同宽的通栏按钮。
- PC 高度 60px，手机高度 56px。
- 墨黑背景、明黄色文字与图标。
- 圆角 12px；手机 10px。
- 文字与图标间距 10px，整体居中。
- 不使用渐变或发光阴影。

状态：

| 状态 | 表现 |
|---|---|
| 默认 | 墨黑底、黄色字 |
| 悬停 | 背景变为 `#30302A`，箭头向右移动 3px |
| 按下 | 整体下移 1px |
| 键盘焦点 | 3px 蓝色外轮廓，间隔 3px |
| 暂不可用 | 灰底深灰字，并显示不可用原因 |

空输入时按钮仍可点击，由校验提示用户补充内容。首页原型不显示“正在核查”或模拟进度。

## 9. 示例问题

示例区左对齐，与输入区边缘对齐。

标题：

> 没想好查什么？试试这些示例

- 字号 13px，次要文字色。
- 标题与示例之间间隔 12px。

示例按钮：

- 白色或透明背景，1px `--border` 边框。
- 圆角 8px。
- 内边距 10px 14px，最小高度 44px。
- 文案左对齐，不截断，允许自然换行。
- 前置小号斜向箭头，图标 16px。
- 悬停时背景变为浅黄色，边框变为墨黑。
- 点击后填入输入框，并显示输入框焦点。

PC 使用可换行的横向排列，按钮间距 8px；手机使用单列通栏排列，间距 8px。不要用横向滑动隐藏示例。

## 10. 错误与提示

输入校验错误放在输入区和主按钮之间：

- 字号 13px，红色文字。
- 左侧 16px 警示图标。
- 顶部间距 8px。
- 文案说明具体问题，例如“图片超过 10MB，请选择较小的文件”。
- 错误出现后允许页面自然增高，不覆盖按钮。
- 通过可访问的状态区域通知读屏软件。

“首页体验版，核查服务尚未接通”使用中性辅助文字，在示例区下方居中呈现，不做红色警告条。

## 11. 提交提示弹窗

有效输入后显示提示弹窗，明确尚未接通核查服务。

文案：

**标题：内容已准备好**

正文：

> 核查服务尚未接通，目前无法生成真假判断。你可以继续修改文字或截图。

主操作：**继续编辑**

样式：

- 遮罩 `rgba(23,23,23,0.42)`。
- 白色背景，2px 墨黑边框，圆角 16px。
- PC 宽度 420px，最大宽度不超过视口减 40px。
- PC 内边距 28px，手机 24px。
- 标题到正文 12px，正文到按钮 24px。
- 正文字号 16px，行高 1.7。
- 主操作按钮通栏，高度 48px。
- 右上角关闭按钮拥有至少 44px 点击区域。

行为：

- 打开后焦点进入弹窗，键盘焦点不跳到背景。
- 支持 Escape 关闭。
- 关闭后恢复至触发按钮，保留全部输入内容。
- 弹窗不能将“内容已准备好”表述成已提交至核查服务。

## 12. 底部说明

文案：

> 核查基于可获取的公开资料，结论可能随新证据更新。  
> 查不到，不等于假。

- 居中排列，最大宽度 640px。
- PC 字号 13px，手机 12px，行高 1.7。
- 第一行使用次要文字色，最后一句可用墨黑中等字重强调。
- 页面底部留白至少 24px，并兼容手机安全区域。
- 不添加未经验证的认证标识、准确率或用户数量。

## 13. 图标与动效

图标统一使用线性风格：

- 描边宽度约 1.8～2px。
- 常用尺寸 16、18、20px。
- 图标不使用 emoji，不混用多套风格。
- 图标与文字垂直居中。

动效：

- 颜色、边框变化：150ms。
- 箭头移动和轻微位移：150～180ms。
- 弹窗出现：150ms 淡入，可伴随不超过 6px 的位移。
- 不使用循环漂浮、跳动或打字机效果。
- 用户开启减少动态效果时，关闭位移动效。

## 14. 响应式验收

至少检查以下视口：

| 视口 | 检查重点 |
|---|---|
| 1440 × 900 | 主体居中、标题有力量、上下留白合理 |
| 1024 × 768 | 标题与输入区比例协调 |
| 768 × 1024 | 平板过渡自然 |
| 390 × 844 | 手机输入、按钮和示例排列清晰 |
| 320 × 568 | 标题不溢出、工具栏不挤压、页面可滚动 |

同时检查：

- 200% 页面缩放仍可使用。
- 长链接、2,000 字文本和三张图片不会破坏布局。
- 手机输入正文至少 16px。
- 键盘焦点清晰，点击区域足够大。
- 页面无横向滚动，弹窗在小屏幕内可完整操作。
- 截图验收同时提供 PC 和手机版本。

## 15. 实施交付要求

6.1 Sol 应将颜色、字号、间距、圆角等集中为可复用变量；按品牌区、输入组件、图片预览、主按钮、示例区和提示弹窗组织代码。

交付可操作页面与启动说明，并说明实际完成的浏览器验证。所有结果、来源与进度展示必须与实际接通的服务能力一致。
